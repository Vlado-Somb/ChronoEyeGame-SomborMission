# CHRONO EYE — регистар архитектонских одлука

**Начело:** Ово је *append-only* историја. Одлуке се не бришу; уместо тога добијају `superseded` и референцу на наследника. Промена Google сервиса, формата датотека, Android/AR понашања, трошкова или правила игре мора бити заведена **пре** имплементације.

**Статуси:** `proposed` = на разматрању; `accepted_for_design` = усвојено као радни правац; `verified_in_test` = проверено на описаном тесту; `superseded` = замењено новом одлуком; `rejected` = одбачено.

## Усвојени радни принципи

### DEC-2026-001 — Један мотор, више градова
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** Сомбор, Будимпешта и наредне игре користе исту логику, а сваки град има свој верзионисани пакет садржаја.
- **Разлог:** Једном решена механика не сме да се преписује за сваку нову мисију.
- **Утицај:** `manifest.json`, стабилни ID-јеви, појединачне мисије.
- **Провера:** нова игра успешно учитана без измене мотора. **Није још извршена.**

### DEC-2026-002 — Web UI + Android bridge + native ARCore
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** Web приказ је главни UI, Android води GPS/дозволе/lifecycle, ARCore води просторни AR. Један заједнички Game State обрађује резултате.
- **Разлог:** Нова тестна архитектура; Unity је извор логике, не циљна платформа.
- **Провера:** једна мисија пролази Web → GPS → native AR → Web → сачувано стање. **Није још извршена.**

### DEC-2026-003 — Преносиви JSON садржај
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** Садржај се пакује у одвојене `missions/`, `waypoints.json`, `dialogues/`, `hints.json`, `timeline.json`, `triggers.json`, `mechanics.json` и `manifest.json`.
- **Референца:** [Sombor content-export PR #2](https://github.com/Vlado-Somb/ChronoEyeGame-SomborMission/pull/2); тренутно кандидат, не production.
- **Провера:** статичка референцијална контрола на извозу обављена; учитавање у нови мотор **није** проверено.

### DEC-2026-004 — Зоне GPS-а и AR fallback
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** WGS84 + Outer/Approach/Close зоне + време потврде; AR сидро је одвојено од GPS координате; слаб или неподржан AR има алтернативни ток.
- **Непотврђено:** радијуси 5–7 m за „Close“ и видљивост 35–75 m за велике фасаде су полазне вредности.
- **Провера:** теренски GPS тест за разноврсне типове локација и проверено AR заклањање/дубина.

### DEC-2026-005 — Референтно бодовање
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** Сомборски почетни профил: +10 задатак, +30 завршена мисија, −2 погрешан одговор. Вредности конфигурисати по игри; бодове обрачунавати највише једном по завршетку.
- **Провера:** поновљени GPS и AR event не смеју дуплирати бодове.

### DEC-2026-006 — Дневник пракси и промена
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** Један централни стандард + append-only регистар одлука + дневник доказа + регистар сервиса + changelog. Нови град прво чита ове датотеке.
- **Провера:** нова мисија комплетно описана и валидирана користећи само стандард и шаблон.

## Одлуке о Google сервисима

### DEC-2026-007 — Један Google Cloud пројекат за платформу
- **Датум:** 2026-10-08; **Статус:** `proposed`
- **Предлог:** један одвојени Cloud пројекат за CHRONO EYE сервисе, са засебним кључевима/OAuth клијентима за Android debug, Android release и Web кад је потребно.
- **Разлог:** централна контрола квота, billing-а и приступа.
- **Није урађено:** пројекат **није креиран**, Project ID и Billing нису верификовани.
- **За усвајање:** одлука власника, проверена правила приступа, праћење трошкова и ревизија кључева.

### DEC-2026-008 — ARCore Geospatial преко ARCore API-ја, условно
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`, **Cloud активација:** `not_configured`
- **Одлука:** Native ARCore је основа AR слоја. Када је за мисију неопходно VPS/Geospatial сидро, укључити **ARCore API** у Cloud пројекту. За Android прво размотрити Google-препоручен **Keyless OAuth 2.0** (package name + SHA-1 debug/release потписа).
- **Разлог:** VPS/Geospatial није обична координата на веб мапи.
- **Провера:** проверити локацијску/VPS доступност, Android capability, исход геопросторног позиционирања и fallback.
- **Извор:** https://developers.google.com/ar/develop/java/geospatial/enable и https://developers.google.com/ar/develop/authorization?platform=android

### DEC-2026-009 — Начин приказа мапе још није закључан
- **Датум:** 2026-10-08; **Статус:** `proposed`
- **Кандидати:** Google Maps JavaScript API у WebView **или** нативни Maps SDK for Android, односно независни Web map adapter ако одговара условима лиценце.
- **Одлука за сада:** WGS84 `waypoints.json` је извор истине; приказ мапе је заменљив адаптер. **Не активирати оба Google Maps API-ја без разлога.**
- **Разлог:** локално пакован WebView може изоставити HTTP `Referer`, па ограничење веб API кључа не функционише поуздано.
- **Провера:** Android debug/release WebView тест, ограничење кључа, offline/online понашање, трошак и лиценца подлоге.
- **Извор:** https://developers.google.com/maps/api-security-best-practices

### DEC-2026-010 — Places/Routes/Geocoding одложити; Roads не користити
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** `Places API (New)` само ако затреба упит за стварна места; `Routes API` само за пешачку навигацију; `Geocoding API` само за претварање адреса; `Roads API` није потребан за пешачку игру.
- **Разлог:** наше GPS тачке и руте приче су наши подаци; додатни Google API-ји нису предуслов.
- **Провера:** нови сервис се може активирати тек са конкретним use-case-ом, проценом квоте/цене и тестом.
- **Извори:** https://developers.google.com/maps/documentation/routes/route-usecases и https://developers.google.com/maps/documentation/roads/

### DEC-2026-011 — Тајне, billing и минималне дозволе
- **Датум:** 2026-10-08; **Статус:** `accepted_for_design`
- **Одлука:** никакви API кључеви, OAuth токени, приватни сертификати ни service-account JSON у Git-у. Кључеви се раздвајају по апликацији/окружењу; приступ је минималан. Billing alerts и quotas се конфигуришу пре јавног коришћења, где је применљиво.
- **Ограничење:** alerts-only Cloud Billing буџет **не зауставља** аутоматски трошкове.
- **Извори:** https://developers.google.com/maps/api-security-best-practices и https://docs.cloud.google.com/billing/docs/how-to/budgets

## Допуне после продукционог пакета Градске куће — 2026-10-08

### DEC-2026-012 — Историјски наратив није заменљив AR туторијалом
- **Статус:** `accepted_for_design`
- **Одлука:** Свака мисија чува уводну причу, историјску чињеницу са извором, стварно едукативно питање, feedback и завршни наратив. AR пре квиза не сме истиснути његову историјску функцију.
- **Референца:** `game-data/sombor/v1/missions/gk.json` на PR #2; 1718 / 1749 / 1842 и питање о 1842 остају.
- **Статус доказа:** редакторски модел записан; Android интеграција није тестирана.
- **Утицај на v0.1:** допуна секције 6/7, без брисања старих историјских текстова.

### DEC-2026-013 — Пет активних AR задатака и равноправни 2D fallback
- **Статус:** `accepted_for_design`
- **Одлука:** `ar_interaction` је део `tasks[]`, обично после GPS доласка. За сваког посебно прописати `interaction`, `assetIds`, просторну политику, услов завршетка, статус ресурса и 2D fallback који решава исти образовни циљ и доноси исте основне поене.
- **Примери:** GK торaњ, MKG боје, NPS позорница, LK наслов „Santa Maria della Salute“, EB неми филм.
- **Разлика:** `active:true` означава усвојен сценарио, **не** извршен ARCore тест. Ручни AR ниšan није аутоматско препознавање торња.
- **Утицај на шему:** додаје `ar_interaction` обавезну типизирану структуру; за стари град примењује се нова content верзија, без аутоматског уписа у претходне пакете.

### DEC-2026-014 — Поново употребљив AR ментор и историјски ехо-ликови
- **Статус:** `accepted_for_design`
- **Одлука:** `systems/characters.json` као заједнички регистар. Професор Влада се може појавити на безбедној равни и ручно поново призвати; глас, титлови, гестикулација, `idle`, показивање, долазак и нестајање су део продукционог пакета. 2D портрет је обавезан fallback.
- **Проширење:** историјске сенке, локални гласови, драматизовани ликови по локацијама, уз извор, права и експлицитну ознаку реконструкције.
- **Статус:** 2D концепт и сценарио постоје; GLB/voice/runtime су `pending`.

### DEC-2026-015 — Четири врсте колекционарских предмета
- **Статус:** `accepted_for_design`
- **Одлука:** `relic` (главни, јединствен по мисији), `golden_seal` (мали стилизовани печати Сомбора 1749, микроприча и ситни бонус), `heart` (романтичне приче), `joker` (јасно фикционални шалjиви моменти). Ситни предмети су необавезни за завршетак главне мисије.
- **Бодовање:** per-game конфигурација; стари профил +10/+30/−2 остаје, додатни бонуси имају ограничења и идемпотентне кључеве. Реликвија не дуплира мисијски бонус.
- **Безбедност:** никакво навођење на коловоз, приватни простор или ходање с подигнутим телефоном.
- **Статус:** дизајн и SVG концепти, не runtime доказ.

### DEC-2026-016 — „Herbarijum“ као видљив албум инвентара
- **Статус:** `accepted_for_design`
- **Одлука:** `systems/album.json` описује стално доступан UX „Моја збирка“, категорије, картice са текстом/извором/местом, закључана стања, напредак по врсти и подршку 2D режиму.
- **Player State:** одвојено чувати `unlockedCollectibleIds`, `pickedSpawnIds`, `firstDiscoveredAt`, `scoreAwardsByKey`, `seenMentorIntros`; без дуплирања награда после рестарта.
- **Приватност:** нема јавне историје кретања играча у Git репозиторијуму.

### DEC-2026-017 — Обавезан продукциони пакет и статус ресурса
- **Статус:** `accepted_for_design`
- **Одлука:** уз сваку мисију `PRODUCTION_BRIEF.md`, `scene-flow.json`, `asset-manifest.json`, `QA_CHECKLIST.md`; ресурс има статус `planned_not_created`, `created_concept`, `integration_pending` или `verified_in_test` искључиво по доказу.
- **Опсег:** наратив, модел сцене, визуелни/текстуални/звучни/просторни асети, права/историјски извори, обавезан fallback, безбедност, тест-критеријуми, релевантни Гит commit/PR.
- **Референца:** `game-data/sombor/v1/production/gradska-kuca/` на PR #2.
- **Миграција:** по новој верзији стандарда v0.2; v0.1 се задржава као претходни запис; `SERVICE_REGISTRY` остаје непромењен јер није донета нова одлука о API приступу.
- **Провера:** није доказана Web/Android/ARCore примена; документовање асета и статичка уредничка структура ≠ теренски тест.

### DEC-2026-018 — CHRONO EYE Web Google Maps adapter (candidate)
- **Датум:** 2026-10-09; **Статус:** `accepted_for_design`, није `verified_in_test` на уређају.
- **Одлука:** за први Web Maps прототип користимо Google Maps JavaScript API и издвојени `web/maps/` модул, по узору на постојећи Heritage Map. Постојећи WGS84 `waypoints.json` остаје извор истине; `data/sombor-demo.json` је само верзионисан snapshot кандидат-грана док `game-data` није спојен у `main`.
- **Безбедност:** без копирања Heritage Maps кључа; засебан ограничен browser key, HTTPS referrer и Cloud одобрење пре јавног Google приказа. Празан кључ покреће координатни преглед.
- **Android/iOS:** WebView + Android Location Engine / iOS location bridge су одвојени будући адаптери. Ова одлука не потврђује њихову интеграцију нити ARCore.
- **Механика:** мапа само приказује GPS zone candidates, никада не потврђује GPS долазак, не чува Player State и не додељује бодове.
- **Провера:** статичка провера `web/maps/tests/maps.test.cjs` и визуелни HTTPS/WebView тест тек предстоје; видети README у PR-у за детаље.
- **Однос према DEC-009:** конкретизује избор Web адаптера за прототип, без брисања раније алтернативе native Maps SDK.
