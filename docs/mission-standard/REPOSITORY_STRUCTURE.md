# CHRONO EYE — организација апликације и градских пакета

Договор власника од 2026-10-09: један постојећи репозиторијум, једна заједничка апликација, одвојени пакети градова. Гране су привремени токови рада и прегледа, не трајне копије платформе по градовима. Репозиторијум за сада задржава име `Vlado-Somb/ChronoEyeGame-SomborMission`.

## Садржај и код

- `game-data/sombor/v1/`: сомборски садржај; тренутни кандидат на PR #2.
- `game-data/budapest/v1/`: будимпештанска кампања, са сопственим manifest-ом, актовима, ликовима, изворима и продукционим документима.
- `docs/mission-standard/`: заједничка правила и уговори; експлицитно верзионисана проширења.
- Постојећи Unity `Assets/`, `Packages/`, `ProjectSettings/` остају на месту као наслеђени извор. Не копирати Unity мотор у сваки градски пакет.
- Прототипови на другим радним гранама задржавају тренутне путање док не прођу свој преглед; ова одлука их не премешта и не мења build конфигурацију.

Циљна структура за каснију, контролисану консолидацију кода:

| Путања | Одговорност |
|---|---|
| `apps/android/` | Android lifecycle, дозволе, GPS, ARCore, bridge |
| `apps/web/` | Мапа, дијалози, задаци, албум |
| `packages/engine/` | Заједнички услови, бодовање и player state |
| `game-data/<city>/v<major>/` | Преносив садржај града |

Ове три кодне путање су циљ, не тврдња да је миграција већ извршена. Прво попис зависности и постојећих workflow-а, затим засебан PR за премештање са провером build-а. Не правити празне дупликате мотора.

## Рад са гранама

`main` је прегледано интегрисано стање; само присуство у main не значи јавну продукциону спремност. `content/<city>-<change>` садржи промену садржаја, `feature/<capability>` развој функције, а `fix/<issue>` исправку. Постојећа имена грана не мењамо само због ове конвенције.

Сваки завршен пакет иде кроз PR ка main. Пре спајања проверити нови main, конфликте у append-only регистрима, content/schema верзије и подршку мотора. Не спајати неусклађен schema кандидат уз тврдњу да је игра оперативна. После спајања грана више није канонски извор садржаја; main и верзионисани пакети јесу.

Апликација бира град преко gameId и manifest-а. Прогрес се одваја по gameId. Неподржане requiredCapabilities изазивају јасно одбијање учитавања, не делимично прескакање логике. Промена садржаја једног града не сме захтевати копирање заједничког мотора.

## Јавно лансирање

Раздвајање развојног и оперативног окружења, безбедносна провера, release signing, јавни медијски ресурси и права, Google Cloud конфигурација и дистрибуција садржаја биће посебан release посао пре јавног лансирања. Овај договор не активира Cloud сервисе, не објављује апликацију и не проглашава развојни пакет production издањем.

Посебан репозиторијум садржаја размотрити тек када је потребна другачија приватност, дозволе приступа или независна дистрибуција. Градови не добијају засебне копије runtime-а ни тада.
