# CHRONO EYE — централни стандард

**Ово је почетна тачка за све будуће игре и мисије.** Овај репозиторијум тренутно садржи изворни Unity пројекат Сомбора; стандард је независан од Unity-ја и важи за нову архитектуру **Web UI + Android + ARCore**.

**Актуелна верзија стандарда:** [Mission Building Standard v0.2](docs/mission-standard/MISSION_STANDARD_v0.2.md)  
**Статус:** усвојен као *радни референтни модел за израду садржаја*; Web/Android/ARCore имплементација још није потврђена теренским тестом.

Документи који се **обавезно читају пре измене игре**:

1. [Рецепт за нове мисије](docs/mission-standard/MISSION_STANDARD_v0.2.md) — структура, механика и поступак.
2. [Регистар одлука](docs/mission-standard/DECISION_LOG.md) — усвојене, пробне и одбачене архитектонске одлуке; укључујући избор сервиса.
3. [Регистар сервиса](docs/mission-standard/SERVICE_REGISTRY.md) — шта се користи, за шта, стање приступа и услови активирања.
4. [Дневник добре праксе](docs/mission-standard/PRACTICE_LOG.md) — *само проверена* искуства, тестови, ограничења и препоруке.
5. [Шаблон продукционог пакета](docs/mission-standard/PRODUCTION_PACKAGE_TEMPLATE_v0.2.md) — обавезан образац за нову мисију.
6. [Историја измена](docs/mission-standard/CHANGELOG.md) — промене стандарда и одлука.

**Референца за податке:** [Sombor Game Data v1.1 + GK production — PR #2](https://github.com/Vlado-Somb/ChronoEyeGame-SomborMission/pull/2), директоријум `game-data/sombor/v1/` у предложеној грани. До спајања PR-а у `main`, садржај је *candidate*, не део `main`.

**Правило:** Сваки нови град добија свој `manifest.json`, мисије и локације; мотор и обавезни уговор података се не дуплирају. Промена сервиса или механике захтева запис одлуке, доказ из теста и ажурирање релевантног документа. Не уписивати API кључеве, OAuth токене ни друге тајне у GitHub.

**Шта је ново у v0.2:** свака нова мисија има обавезан наратив, прави образовни задатак, AR/2D fallback, опциони AR ментор, 4 класе предмета (реликвије, златни печати, срца, џокери), видљив албум и 4 продукциона документа. У `docs/mission-standard/MISSION_STANDARD_v0.1.md` остаје непромењена претходна верзија.

**Напомена о статусу:** Сомборски v1.1 JSON и производни пакет су тренутно на PR #2; нови стандард их референцира као *accepted_for_design*, не као већ спојен и теренски проверен runtime. Ова допуна сама не активира Google API сервисе.

**Организација репозиторијума:** [једна апликација и одвојени пакети градова](docs/mission-standard/REPOSITORY_STRUCTURE.md), одобрено 2026-10-09. Градови су директоријуми, не трајне гране; радне гране служе припреми и прегледу пре спајања.
