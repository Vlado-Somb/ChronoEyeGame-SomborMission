# CHRONO EYE Budapest

**Град који није пристао да нестане** — шест актова једне будимпештанске кампање. Припремљен наративни и продукциони пакет, content 1.0.0; није готов APK.

Почети од [STORY_BIBLE.md](narrative/STORY_BIBLE.md), затим [комплетног дијалога](narrative/DIALOGUE_SCRIPT.txt), [визуелне режије](narrative/VISUAL_DIRECTION.md) и [уредничког увида](narrative/EDITORIAL_REVIEW.md). Улаз за интеграцију је [manifest.json](manifest.json); семантика проширења је у [DATA_CONTRACT.md](DATA_CONTRACT.md).

## Шта је стварно припремљено

26 сцена, 167 ауторских реплика; 18 задатака, шест интеракција са равноправним 2D решењем, 18 хинтова, шест реликвија, регистри ликова/сигнала/извора, картице доказа, шест комплетних продукционих пакета и оригинални SVG мотиви. Два прихватљива завршетка и једна исправљива погрешна одлука. Текст је српска ћирилица.

Нису готови: продукциони GLB модели, снимљени гласови, сценске анимације, native bridge и теренска геопросторна поставка. Cathedral.FBX је постојећи кандидат са непотврђеним историјским идентитетом. Координате су кандидати; Табан намерно нема измишљену координату/висину. Public release остаје блокиран до наведених провера.

## Репродукција и провера

```sh
python game-data/budapest/v1/tools/build_package.py
python game-data/budapest/v1/tools/validate_package.py
```

Build чита DIALOGUE_SCRIPT.txt и уредничке спецификације у builder-у. За измену генерисаних JSON фајлова изменити builder, па поново покренути проверу. Наративни Markdown и provenance су независни извори. [QA_REPORT.md](QA_REPORT.md) раздваја статичку проверу од непокренутог Android/теренског теста.
