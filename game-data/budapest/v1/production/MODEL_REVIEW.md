# Преглед постојећих модела

Репозиторијум: Vlado-Somb/ChronoEyeGame-SomborMission. Полазни main commit: 02a31188fc77462e972ce611a27533a6c7f1283e.

- `Assets/Model/Cathedral.FBX`: blob 9ca3b6951cf1c4a014fa9b3e28e4e13a021aa1b5, 381264 bytes, бинарни FBX 7400.
- Техничким читањем нађено је девет низова геометрије: 2057, 16, 6, 6, 6, 6, 6, 6 и 4 vertex записа. Model имена: Cathedral и Ivy01–Ivy08.
- Прегледана је ортографска пројекција сирових vertex података. То није пуни render са model трансформацијама, материјалима и texture ресурсима; не доказује да је модел историјски Табан.
- Није извезен GLB под лажном ознаком готове Табанске цркве. Следећи моделарски корак: пуни import, преглед трансформација и материјала, поређење са референтном фотографијом, временски пресек, размера, друге стране и лиценца.
- У истом Git стаблу постоје `Assets/MATERIJALI/Likovi 3D  FBX models/Nikola Tesla.fbx` и `jovan_ducic_ghost.fbx`. Само постојање не доказује анимациону/мобилну спремност.

Постојећи Budapest Waypoint Database има празан низ waypoint-а. Координата Амбасаде преузета је из Budapest 1 Mission као legacy кандидат. Наслеђено altitude=150 није увезено као проверена AR висина. Нису преузети serialized isCompleted флагови из старе пробне мисије.
