# Budapest content contract 1.2.0-budapest-draft.1

Ово је проширење за пројектовање над примером 1.1.0, не објављена глобална runtime шема. Старе сомборске датотеке нису промењене. Loader који не подржава requiredCapabilities мора одбити активирање игре са разумљивом поруком, не игнорисати гранања.

## Нормативна семантика кандидата

- `scene-flow.nodes` је ауторитет редоследа унутар акта. `tasks` описују обавезне задатке, али последњи квиз сам не завршава акт.
- `dialogue` чвор чека крај или Skip. Skip бележи сажетак критичног догађаја и означава транскрипт доступним; не довршава следећи task. Чвор који има `setFlag` примењује га атомски при завршетку.
- `task` чвор чека резултат мотора. За `ar_interaction` тачне везе су у `successCondition.allEvidenceMappings`; input мора садржати исти скуп једном сваку везу, без погрешних додатака. Клијентско тапкање само по себи није успех.
- `choice` чвор чека choice ID, уписује `setFlag`, прелази на `next`. То није квиз: нема −2. Само два валидна финална избора воде у FINISH; прихватање савршене истине се враћа на DECIDE.
- `checkpoint` аутоматски атомски чува стање и иде даље; `instruction` чека потврду читања.
- `mission_completion` проверава све requiredTaskIds, јединствени awardKey и валидан пут до тог чвора. Тек тада +30, relic и MISSION_COMPLETED. Накнадно слушање дијалога не шаље поново овај догађај.
- `timeline` је индекс flow датотека. `triggers` услови се читају са payload-а догађаја; за празну листу `all` је true. onlyOnce се трајно чува. Наредни акт се откључава, али не почиње говор током трансфера.
- `optionalSceneIds`: доступно из менија приче у одговарајућем акту. Одбијање у 0 не закључава напредак. Лазаревић није потребан за награду.
- GPS/manual: `navigationEnabled:false` значи да координата није за production навигацију. Null координата забрањује GPS процену; editor/2D пролаз користи ручну потврду означену као manual. Нема fake GPS догађаја.
- Предложене зоне нису AR сидра. Неподржан режим прелази у 2D са истим картицама и условом.
- Score floor је 0. −2 само за submit нетачног квиза, једном по јединственом attemptId; поновљени transport event нема другу казну. Хинтови су бесплатни.
- Idempotency scope је gameId + стабилни task/mission ID + awardType, уз трајни ledger. Верзија садржаја је metadata, НЕ нови простор награђивања приликом надоградње. replay исте кампање подразумевано не даје поново бодове.

## Чување и миграција

Овај град нема претходни објављени player state. Сомборско стање остаје под другим gameId. Ново стање додаје currentFlowNodeId, storyFlags, processedAttemptIds и evidenceSelections поред основних поља. Будућа измена текста без промене значења чува ID-јеве и ledger; нови schema major захтева засебан migration map. Прекид између награде и save-а мора бити транскацијски или replay-safe. Не брисати награде и не ресетовати акт због слабог GPS-а.

## Уговори који тек треба да добију имплементацију

Нативни bridge, renderer за картице, геопросторни приказ, voice плејер, production save engine и global schema validator нису додати овим пакетом. Статички validator проверава овај садржај и граф; не доказује рад APK-а. Језик је sr-Cyrl; HU/EN локализација је следећи уреднички посао, не аутоматски претпостављено готов превод.
