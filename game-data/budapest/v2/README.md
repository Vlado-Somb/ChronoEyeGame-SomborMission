# CHRONO EYE — BUDAPEST v2

Пролог + чинови I–VI. Постојећи сценарио је очуван: 48 драмских сцена, 375 реплика, 21 задатак, 7 AR/2D наставних корака и 7 реликвија.

## Извор истине
- manifest.json — обавезан loader entrypoint, contentVersion, capability gate, инвентар.
- ../v1/narrative/STORY_BIBLE.md — одобрени канон v0.2.1. Старе Budapest v1 mission/dialogue датотеке су историја израде, НЕ active script.
- screenplay/ — ауторски мастер-текстови по сценама, никада аутентичан говор историјских личности.
- dialogues/, missions/, production/act-0..6/ — директно повезана структура. Сваки акт има сва четири продукциона документа.
- production/AUDIO_DIRECTION.md + VISUAL_DIRECTION.md — сценско-медијска режија, нарочито дуги разговор Овсата у кафеу Централ и Гелерт/Табан.

## Покретање статичког QA
Из корена репозиторијума: node game-data/budapest/v2/tools/validate-v2.mjs
Проверити QA_REPORT.md за доказе и release блокаторе.

## Статус
Сценаријска/пакетна миграција је припремљена за накнадни fine-tuning. Нису активни GPS, ARCore, Web bridge нити production гласови/3D: 11 координатних ставки и 13 планираних asset-а чекају стварну проверу/израду. Важно: више локација у акту V није геодетски потврђена, а прелаз моста није AR станица. Не објављивати као играбилну мисију.
